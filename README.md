
# PricePulse
## AI-Based Dynamic Pricing and Revenue Optimization Platform

### Project Overview
PricePulse is a machine learning-based e-commerce pricing system that analyzes product demand, stock availability, competitor prices, weather conditions and driver availability.

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Q-Learning

### Key Features
1. Demand prediction
2. Dynamic price recommendations
3. Competitor price analysis
4. Stock optimization
5. Demand forecasting
6. Reinforcement learning simulation

### How to Run
Install dependencies:

pip install pandas numpy scikit-learn

Run:

python pricepulse_project.py
